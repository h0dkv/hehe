# Фенерите на Уилоумър

Уютно приключение в малко селце, създадено с HTML, CSS и JavaScript без допълнителни зависимости. Разходи се из Уилоумър, помогни на съседите да се подготвят за фестивала на фенерите и избери как да прекараш вечерта.

## Игра на компютър

Отвори `index.html` в браузър. Не е необходима инсталация или компилация.

## Публикуване чрез GitHub Pages

1. Качи хранилището в GitHub.
2. Отвори **Settings > Pages** в хранилището.
3. В **Build and deployment** избери **Deploy from a branch**.
4. Избери своя branch и папката `/(root)`, след което запази.

GitHub Pages ще публикува директно `index.html`. Играта няма сървърен код, стъпка за компилация или външни зависимости.

## Управление

- **Стрелки** или **W / A / S / D** за движение
- **E** или **Space** за разговор и взаимодействие
- На телефон използвай стрелките на екрана и бутона **Говори / вземи**
